# wcstat — сквозная программа РГР

`wcstat` считает у текстового файла **строки, слова и байты** — так же, как команда `wc`. Одна и та же программа с разными режимами служит объектом исследования в РГР, начиная с ЛР 4: от работы к работе в ней появляются процессы, канал, сигналы, потоки, мьютексы, память и очередь сообщений. Программа одинакова у всех студентов; различаются только числа (параметры запуска) — они зависят от варианта.

Изменять программу не нужно. Читать её нужно только в части, относящейся к текущей работе (каждый режим — в своём файле).

## Сборка

```bash
cd ~/<фамилия>/rgr/programs
make
```

Получится файл `wcstat`. Предупреждений быть не должно. `make clean` удаляет собранное.

## Файл для подсчёта

Все исследования выполняются на одном и том же файле. Создайте его в ЛР 4; число строк `N` — из вашего варианта (таблица в части 2 `task-04.md`). Для ЛР 8 и 10 нужен больший файл `big.txt` — его `N` берётся из таблицы ЛР 8:

```bash
seq 1 <N> | sed 's/$/ alpha beta gamma/' > data.txt
wc data.txt
```

Для большого файла: `seq 1 <N> | sed 's/$/ alpha beta gamma/' > big.txt`. Команда `wc` — эталон: `wcstat` обязан дать те же три числа (кроме режимов с ошибкой, где потери и есть предмет исследования).

## Режимы

| Работа | Режим | Что делает |
|---|---|---|
| ЛР 4 | `wcstat data.txt` | один процесс читает файл блоками по 4096 байт (`pread`) и считает |
| | `-b байт` | размер блока чтения (во всех режимах) |
| ЛР 5 | `-p K` | K потомков, каждый считает свою часть файла и печатает её |
| | `-s мс` | пауза после каждого блока: имитация медленного диска, чтобы успеть посмотреть `ps` |
| | `-h сек` | перед завершением главный процесс ждёт столько секунд |
| | `-n` | родитель не вызывает `wait` (зомби) |
| ЛР 6 | `-p K -c` | потомки отдают результат родителю через канал, записями по 64 байта |
| | `-r байт` | размер записи канала (32…4096) |
| | `-d сек` | родитель начинает читать канал через столько секунд |
| | `-l` | родитель не закрывает свой записывающий конец канала (ошибка) |
| ЛР 7 | `-m` | на время работы заблокированы SIGINT, SIGTERM, SIGUSR1 |
| | (всегда в `-p`) | SIGINT, SIGTERM — остановиться; SIGUSR1 — отметить; SIGCHLD — посчитать |
| ЛР 8 | `-t T` | T потоков считают свои части в общий итог **без блокировки** |
| | `-x` | общий итог обновляется под мьютексом |
| ЛР 9 | `-t T -q Q` | читатель кладёт блоки в очередь на Q мест, T потоков берут и считают |
| | `-D` | нечётные потоки берут два мьютекса в обратном порядке (ошибка) |
| ЛР 10 | `-M all` | весь файл читается в память (`malloc`), затем считается |
| | `-M map` | файл отображается в память (`mmap`) |
| | `-w` | после подсчёта потомок пишет в каждую страницу (копирование при записи) |
| ЛР 11 | `-S [-k ключ]` | сервер: принимает запросы по очереди сообщений System V |
| | `-a файл [-k ключ]` | клиент: просит сервер посчитать файл |

## Где какой файл

| Файл | Содержимое | Работа |
|---|---|---|
| `wcstat.c` | разбор параметров, подсчёт одного блока, основной режим | 4 |
| `procs.c` | потомки, канал, сигналы | 5, 6, 7 |
| `threads.c` | потоки, мьютекс, очередь | 8, 9 |
| `mem.c` | память | 10 |
| `ipc.c` | сервер и клиент | 11 |
