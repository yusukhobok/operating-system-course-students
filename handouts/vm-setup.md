# Установка рабочего окружения: VirtualBox, Ubuntu Server 16.04 и материалы работ

Все лабораторные работы с ЛР 3 выполняются в виртуальной машине (ВМ) с Ubuntu Server 16.04 под управлением Oracle VirtualBox. В ВМ **нет интернета**, поэтому всё необходимое устанавливается с готовых образов-дисков:

| Файл | Что это |
|---|---|
| `ubuntu-16.04.<N>-server-amd64.iso` | установочный диск Ubuntu Server 16.04 |
| `ospkgs.iso` | пакеты: компилятор `gcc`, `make`, `gdb`, `strace` и др. |
| `oslabs.iso` | готовые программы всех лабораторных работ (каталоги `lab04` … `lab11`) |
| установщик VirtualBox (`VirtualBox-<версия>-Win.exe`) | программа для запуска виртуальных машин; нужен только на ноутбуке — в классе VirtualBox уже установлен |

**В классе** три `.iso`-файла лежат на рабочем столе компьютера; далее «папка с образами» — это рабочий стол.

**На своём ноутбуке** сначала скопируйте эти три файла с компьютера класса на флешку, а с флешки — к себе в любую папку (она и будет «папкой с образами»), и скачайте VirtualBox (шаг 1). Дальше все шаги те же, что в классе, — окружение получится одинаковым.

**Тексты заданий** (`task-NN.md`) и руководств (`guide-NN.md`) читайте не в ВМ, а на своём устройстве: на GitHub в репозитории курса (ссылку даст преподаватель) или в файлах, которые преподаватель передаст на флешке. В ВМ из материалов нужны только программы из `oslabs.iso`.

**На компьютере класса ВМ может быть уже создана** — другим студентом или преподавателем. Это нормально: за одним компьютером работают разные студенты, у каждого — своя папка в одной и той же ВМ. Проверьте: запустите ВМ (шаг 6) и выполните `gcc --version`. Если версия выводится, **шаги 2–4 пропустите** и переходите к шагу 5.

## Шаг 1. Установка VirtualBox (только на ноутбуке)

**В классе VirtualBox уже установлен — пропустите этот шаг.** Пропустите его и на ноутбуке, если «Oracle VM VirtualBox» уже есть в меню «Пуск».

1. Скачайте установщик для Windows (`Windows hosts`) со страницы загрузок на сайте virtualbox.org и запустите `VirtualBox-<версия>-Win.exe` (нужны права администратора). Ноутбуки Apple на процессорах M (ARM) для этого курса не подходят.
2. Во всех окнах нажимайте **Next**, ничего не меняя; на вопрос об установке драйверов сетевых адаптеров отвечайте **Yes / Установить**.
3. Нажмите **Install**, затем **Finish**. Дополнительные пакеты (Extension Pack) **не нужны**.

Если при создании или запуске ВМ VirtualBox пишет про `VT-x` или `AMD-V`, виртуализация отключена в BIOS компьютера: включите её (параметры `Intel Virtualization Technology`, `SVM Mode`) или попросите преподавателя.

## Шаг 2. Создание виртуальной машины

1. Запустите VirtualBox, нажмите **Создать**.
2. Укажите: **Имя** — `ubuntu16`; **Тип** — `Linux`; **Версия** — `Ubuntu (64-bit)`. Нажмите **Далее**.
3. **Объём памяти** — `1024` МБ (не меньше: в ЛР 10 нужен 1 ГиБ). **Далее**.
4. **Жёсткий диск** — «Создать новый виртуальный жёсткий диск» → тип `VDI` → **динамический** → размер `10` ГБ. **Создать**.
5. Выберите созданную машину → **Настроить**:
   - **Система → Процессор**: поставьте `2` процессора (для ЛР 8 нужно больше одного ядра);
   - **Носители**: щёлкните по строке `Пусто` (оптический привод), справа нажмите значок диска → «Выбрать файл диска…» → укажите `ubuntu-16.04.<N>-server-amd64.iso` из папки с образами;
   - **Сеть → Адаптер 1**: снимите галку **Включить сетевой адаптер** (интернета всё равно нет, а установщик без него не будет зависать на поиске сети).
   Нажмите **OK**.

## Шаг 3. Установка Ubuntu Server 16.04

Запустите машину (**Запустить**). В окне ВМ мышь не работает — только клавиатура: **Tab**, **стрелки**, **Enter**, **пробел** (отметить пункт). Чтобы вернуть мышь в Windows, нажмите правый **Ctrl**.

Экраны установщика (названия на английском; порядок и тексты могут немного отличаться):

1. **Language** — `English`. **Install Ubuntu Server**.
2. **Select your location** — любая страна (например, `other → Asia → Russian Federation`).
3. **Configure the keyboard** — `No` (не определять), раскладка `English (US)`.
4. Если установщик спросит про сеть — `Do not configure the network at this time`.
5. **Hostname** — `ubuntu`.
6. **Full name** и **username** — `user`. **Password** — `1` (один и тот же логин и пароль на всех ВМ курса, чтобы любой студент мог войти). Установщик предупредит, что пароль слишком слабый (`Use weak password?`) — ответьте `Yes`. **Encrypt your home directory** — `No`.
7. **Time zone** — подтвердите предложенную.
8. **Partition disks** — `Guided - use entire disk` → выберите единственный диск → `Yes` (записать изменения). Если спросят про `LVM`, выберите вариант без него.
9. **HTTP proxy** — оставьте пустым, **Continue**. **Updates** — `No automatic updates`.
10. **Software selection** — **ничего не отмечайте** (никаких пакетов `OpenSSH` и т. п.), **Continue**.
11. **Install the GRUB boot loader** — `Yes`, диск `/dev/sda`.
12. **Installation complete** — **Continue**. ВМ перезагрузится. Если снова запустился установщик, выключите ВМ (**Машина → Закрыть → Выключить**), в **Настройки → Носители** извлеките диск (`Удалить диск из виртуального привода`) и запустите заново.

После перезагрузки появится приглашение `ubuntu login:`. Введите логин `user` и пароль `1` (при вводе пароля символы не отображаются).

## Шаг 4. Установка необходимого ПО из `ospkgs.iso`

1. В меню окна ВМ: **Устройства → Оптические диски → Выбрать файл диска…** → `ospkgs.iso` из папки с образами.
2. В ВМ:

```bash
sudo mount /dev/cdrom /mnt
ls /mnt
sudo dpkg -i /mnt/*.deb
sudo umount /mnt
```

`ls` должен показать много файлов `.deb`. `dpkg` напечатает длинный ход установки — это нормально. Если `/dev/cdrom` не найден, посмотрите `lsblk` и подставьте устройство (обычно `/dev/sr0`).

3. Проверьте:

```bash
gcc --version
make --version
strace -V
gdb --version
```

Каждая команда должна напечатать версию. Если какой-то нет или `dpkg` сообщил о проблемах с зависимостями — скажите преподавателю.

### Русские буквы в консоли

Если вместо русских букв в выводе программ квадраты, «?» или коды, выполните один раз:

```bash
sudo update-locale LANG=C.UTF-8
sudo dpkg-reconfigure console-setup
```

(`C.UTF-8` пишется с **заглавной** C.) В диалоге выберите: кодировка — `UTF-8`; набор символов — `Cyrillic - Slavic languages (also Bosnian and Serbian Latin)`; шрифт — `Fixed`; размер — `16`. Затем `sudo setupcon`, выйдите из системы (`exit`) и войдите заново. Проверка: `printf '\xd0\xbf\xd1\x80\xd0\xb8\xd0\xb2\xd0\xb5\xd1\x82\n'` должна напечатать слово «привет».

## Шаг 5. Своя папка и материалы из `oslabs.iso`

Каждый студент работает в **своей папке**, названной по фамилии латиницей строчными буквами (русские буквы в именах папок лучше не использовать). Ниже в примерах — `ivanov`; подставьте свою фамилию.

1. Подключите образ: **Устройства → Оптические диски → Выбрать файл диска…** → `oslabs.iso`.
2. В ВМ (войдя как `user`):

```bash
mkdir ~/ivanov
sudo mount /dev/cdrom /mnt
cp -r /mnt/* ~/ivanov/
sudo umount /mnt
chmod -R u+w ~/ivanov
ls ~/ivanov
```

Должны появиться каталоги `lab04`, `lab05`, …, `lab11`; в каждом — `programs/` (готовые программы с `Makefile`) и `skeleton/` (заготовки для задач со звёздочкой).

3. Проверьте сборку:

```bash
cd ~/ivanov/lab04/programs
make
```

Должны собраться программы `copy` и `lines` без предупреждений.

**Что важно знать:**
- В руководствах к лабораторным (`guide-NN.md`) путь к материалам записан как `~/<фамилия>/lab04`, `~/<фамилия>/lab05` и т. д. — подставляйте имя своей папки. Шаг 1 каждого руководства предполагает, что материалы уже скопированы по этому шагу 5.
- Не работайте в чужих папках и не удаляйте их. Если нужно начать заново — удалите **свою** папку (`rm -r ~/ivanov`) и повторите копирование.
- Ваши файлы остаются в ВМ между занятиями. Отчёт делайте по снимкам экрана и результатам из своей папки.

## Шаг 6. Каждое занятие

1. Запустите VirtualBox, выберите машину `ubuntu16`, нажмите **Запустить**.
2. Войдите как `user` (пароль `1`).
3. Перейдите в свою папку: `cd ~/ivanov/lab04/programs` (номер работы — свой).
4. Снимки экрана для отчёта делайте клавишей **PrintScreen** (Windows сохранит снимок окна VirtualBox в буфер обмена; вставьте в Paint или Word) или программой «Ножницы».
5. В конце работы выключите ВМ: `sudo poweroff` (не закрывайте окно крестиком без выключения).

## Если что-то не получилось

| Симптом | Причина | Что делать |
|---|---|---|
| При создании ВМ нет пункта `Ubuntu (64-bit)` | отключена виртуализация в BIOS | включить `VT-x`/`AMD-V` в BIOS или обратиться к преподавателю |
| Установщик Ubuntu зависает на сети | не отключён сетевой адаптер | снять галку «Включить сетевой адаптер» (шаг 2) |
| После установки снова запускается установщик | в приводе остался установочный диск | выключить ВМ, извлечь диск в **Настройки → Носители** |
| `mount: no medium found` | образ не подключён к ВМ | выбрать файл диска в меню **Устройства → Оптические диски** и повторить `mount` |
| `/dev/cdrom` не найден | у привода другое имя | `lsblk`; смонтировать `/dev/sr0` |
| `gcc: command not found` | ПО из `ospkgs.iso` не установлено | повторить шаг 4 |
| `make: *** No targets specified and no makefile found` | вы не в каталоге `programs` | `cd ~/<фамилия>/lab04/programs` |
| `Permission denied` при `cp` или `make` | файлы скопированы с образа только для чтения | `chmod -R u+w ~/<фамилия>` |
| `update-locale: Error: invalid locale settings` | неверно написано `LANG` | `C.UTF-8` — с заглавной C |
| Русские буквы не читаются в `less`/`vim` | не включена UTF-8-локаль | `export LANG=C.UTF-8`; насовсем — `sudo update-locale LANG=C.UTF-8` и перезайти |
| Не работает мышь в окне ВМ | в Ubuntu Server мыши нет | пользоваться клавиатурой; правый **Ctrl** возвращает мышь в Windows |

## Дома, на своём ноутбуке

Работайте по тем же шагам 1–6 с теми же тремя образами: скачайте VirtualBox, скопируйте образы с компьютера класса, создайте ВМ с Ubuntu Server 16.04, поставьте ПО из `ospkgs.iso` и материалы из `oslabs.iso` (материалы берутся из образа, интернет для этого не нужен). Так среда дома совпадает с классом, и результаты команд будут теми же. Сетевой адаптер ВМ при желании можно включить после установки, но для работы он не нужен.
