# Шаблон отчёта по лабораторной работе

Отчёт — один на работу. Оформление (поля, шрифт, нумерация страниц, титульный лист) — по требованиям кафедры. Здесь только состав отчёта. Что именно из конкретной работы попадает в отчёт, сказано в разделе «Требования к отчёту» её задания (`task-NN.md`).

---

## Титульный лист

- Министерство, университет, кафедра — по требованиям кафедры.
- **Лабораторная работа № N. <Название из заголовка task-NN.md>**
- Дисциплина «Операционные системы».
- Выполнил: ФИО, группа, **номер варианта**.
- Проверил: ФИО преподавателя.
- Город, год.

## 1. Цель работы

Скопировать из задания, одним-двумя предложениями.

## 2. Исходные данные

- Вариант № …: параметры из таблицы вариантов (строка таблицы целиком).
- Система, в которой выполнялась работа: вывод `uname -r` и строка `PRETTY_NAME` из `/etc/os-release`.

## 3. Ход работы

По каждому пункту задания — отдельный подраздел с номером пункта:

### Пункт 1. <Коротко, что делалось>

1. **Команда** — текстом, так, чтобы её можно было скопировать:

   ```
   strace -c ls /etc
   ```

2. **Результат** — снимок экрана (места отмечены в guide значком 📷) или текстом существенная часть вывода. Длинный вывод сокращается: оставляются строки, о которых идёт речь, пропуск обозначается `...`.
3. **Что видно** — 1–3 предложения: какое число или строка вывода отвечает на вопрос пункта.

## 4. Часть 2 (по вариантам)

Так же, как ход работы: команда → результат → что видно. Плюс таблица результатов, если её требует задание (например, «размер буфера — время — число вызовов»).

## 5. Ответы на вопросы задания

Если в пунктах задания есть вопросы «объясните», «почему» — ответы своими словами, 2–5 предложений на вопрос, со ссылкой на свой вывод («в выводе `ps` в пункте 3 видно, что …»). Копировать текст лекции или справки `man` не нужно.

## 6. Задача со звёздочкой (если делалась)

- Текст программы (или ссылка на файл, если отчёт электронный).
- Команда сборки и 2–3 запуска с выводом, в том числе запуск с ошибкой (несуществующий файл, неверные параметры).

## 7. Выводы

3–5 предложений: что вы увидели такого, чего не ожидали, и каким механизмом из лекции это объясняется. Не «я изучил команды», а «оказалось, что `printf` при выводе в файл вызывает `write` один раз, потому что …».

## Как сделать снимок экрана

Снимок делается на хост-системе (на ноутбуке, вне ВМ): в Windows — `Win+Shift+S`, в Linux — клавиша `PrtSc` или программа «Снимок экрана». В снимке должно быть видно команду и её вывод. Если вывод не помещается в окно, сократите его (`| head -20`) или сделайте два снимка.

Чтобы перенести текстовый вывод из ВМ без снимка, сохраните его в файл (`команда > out.txt 2>&1`) и откройте файл в редакторе — или скопируйте из окна терминала мышью, если ВМ это позволяет.
